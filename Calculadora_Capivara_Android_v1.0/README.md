# Calculadora Capivara — Android v1.0

Projeto independente derivado da versão 1.7.1 da Calculadora e Calendário Capivara.

- Application ID: `br.com.capivara.calculadora` (pode ser instalado junto com os outros aplicativos).
- Mantém os 13 wallpapers, miniaturas, tema Frutiger Aero e navegação Edge-to-Edge.
- Abre diretamente na tela principal de calculadora capivara.
- Para compilar: `gradle assembleDebug` na pasta raiz, ou pelo GitHub Actions.
- Os ícones permanecem provisoriamente iguais ao aplicativo original; poderão ser personalizados depois.
- Compilação e teste em dispositivo ainda não realizados.
